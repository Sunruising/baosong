# 亚马逊涉税报送差异拆解（免费版）

把“税局收到的亚马逊报送数”和“卖家后台的数”之间的差额拆开讲清楚的网页小工具。

- 在线使用：https://sunruising.github.io/baosong/
- 先看示例（虚构数据，不用准备文件）：https://sunruising.github.io/baosong/tool.html?demo=1
- 下载离线版（单个 HTML 文件，双击即可用）：https://github.com/Sunruising/baosong/releases/latest/download/baosong-offline.html

## 它做什么

把亚马逊发来的季度涉税报告，加上卖家后台导出的报告拖进网页，工具把“报送的收入净额”和“后台 Income”之间的差额拆成几项原因：汇率、收入构成、代收代缴税费、附加费、时间口径、退款跨期、站点覆盖、残差。起点加各项等于终点，精确到分；每一项都能展开，追到原始文件的具体行。还可以一键导出 Excel。

能处理的报告：

- 季度报告：亚马逊邮件里的季度涉税报告（xlsx）
- 日期范围报告：卖家后台的交易报告（csv），每个站点一份
- 亚马逊配送货件报告（txt），逐月导出，用来按发货日对齐季度
- 可选：fees 逐笔费用文件、欧洲站增值税交易报告（VTR）

导出报告前，请先把卖家后台切换到英文界面。

## 隐私

- 所有计算都在你自己的浏览器里完成，文件不上传，没有服务器接收数据。
- 工具页设置了内容安全策略（`default-src 'none'; connect-src 'none'`），浏览器层面禁止它发出任何网络请求，断网也能用。
- 想自己验证：打开工具页，按 F12 打开开发者工具，切到“网络（Network）”，再拖入文件计算，除了打开页面本身，不会有任何请求。
- 只有首页（`index.html`）接入了不蒜子访问计数，只统计打开次数；工具页和离线版不联网。

## 怎么用

1. 打开工具页，把文件拖进去（可以一次拖多个）。
2. 确认识别结果：选季度、汇率口径、时区，确认每个文件属于哪个卖家记号和站点。
3. 查看差异桥接，点开某一项看明细，需要时导出 Excel。

## 免责声明

本工具只做数据整理和差异解释，不构成税务意见。它不计算应补多少税、应申报多少，也不评价哪种申报口径是否合规。
